ROLE & OBJECTIVE

You are a senior full-stack engineer and UI/UX designer. Build a complete, modern, responsive, production-quality marketing website for a local automobile garage/workshop. The site is the garage's official online identity — it must build trust, showcase professionalism, and drive customers to call or visit. Treat this like a real client project: production-grade code, clean architecture, and a design that feels premium and automotive-inspired rather than templated.

Do not ask clarifying questions before starting — use sensible defaults and placeholder content/assets everywhere real content isn't provided, and clearly mark every placeholder so the owner can swap it later.


1. TECH STACK


Framework: Next.js (App Router) with React and TypeScript
Styling: Tailwind CSS with a custom design-token theme (see Section 4)
Animation: Framer Motion for scroll/hover/entry animations; CSS keyframes for ambient effects (light streaks, glow, wheel rotation)
Icons: Lucide React
Forms: React Hook Form + Zod validation
Image handling: Next.js <Image> with lazy loading and responsive sizes
Deployment target: Replit's Node.js hosting, fully static-friendly where possible
Component-driven architecture, strict typing, no unused code, no console errors/warnings



2. DEVELOPMENT PHASES

Build in this order, committing working code at each phase:


Phase 0 — Scaffolding: Next.js + TypeScript + Tailwind setup, folder structure, design tokens, global layout, fonts, favicon.
Phase 1 — Core Layout: Navbar, Footer, floating action buttons, page shell, smooth-scroll config.
Phase 2 — Hero & Landing: Cinematic hero section with animated elements.
Phase 3 — Content Sections: About, Services, Why Choose Us, Work Process.
Phase 4 — Social Proof: Gallery, Testimonials, Quotes.
Phase 5 — Conversion Sections: Location/Map, Contact (form + direct actions).
Phase 6 — Polish: Animations pass, responsive QA, accessibility audit, SEO/meta, performance optimization.
Phase 7 — Optional Features: Dark mode, booking form, FAQ, newsletter, emergency banner (build behind clean toggles so they can be enabled later).

4.2 Typography


Headings: A bold, condensed, modern sans-serif (e.g., "Sora" or "Space Grotesk") — conveys precision and speed.
Body: A highly legible sans-serif (e.g., "Inter" or "Manrope").
Load via next/font for performance. Define a type scale: text-hero (56–72px desktop / 32–40px mobile), h1–h4, body, caption.


4.3 Visual Language


Glassmorphism panels (backdrop-blur, translucent surface + thin border) for nav, cards on top of imagery, and floating stat panels.
Soft, layered shadows (shadow-lg/shadow-2xl with a subtle red/orange glow on hover for CTAs).
Rounded corners: rounded-2xl for cards, rounded-full for buttons/pills.
Consistent 8px spacing scale; generous section padding (py-20–py-32 desktop, py-12–py-16 mobile).

8. ANIMATION REQUIREMENTS


Every section fades/slides into view once on scroll (Intersection Observer via Framer Motion whileInView), never re-triggering distractingly on scroll-up.
Parallax on hero background (subtle, capped movement).
Counter count-up animations (Why Choose Us).
Card hover: lift + shadow glow + icon accent shift.
Button ripple effect on click.
Animated gradient backgrounds behind the Quotes and Hero sections.
Occasional subtle car silhouette or speed-line sweep across a section divider (used sparingly, not on every section).
Wheel-rotation micro-animation used as a loading spinner ("speedometer" style loader) during route/data transitions.
All animations must respect prefers-reduced-motion and degrade to simple fades when set.
Keep everything performant: prefer CSS transforms/opacity, avoid layout-thrashing properties, cap simultaneous animated elements.



9. RESPONSIVE BEHAVIOR


Breakpoints: mobile (<640px), tablet (640–1024px), laptop (1024–1440px), desktop (1440px+).
Navbar collapses to a drawer below tablet.
Grids reflow: Services 4→2→1 columns; Gallery masonry adjusts column count; Work Process switches from horizontal to vertical timeline below tablet.
Touch-friendly tap targets (min 44px) on all interactive elements on mobile.
Test and ensure no horizontal overflow at any breakpoint.



10. ACCESSIBILITY


Semantic HTML landmarks (header, nav, main, section, footer).
All images have descriptive alt text (or alt="" for decorative ones).
Sufficient color contrast against the dark theme (verify accent-on-dark meets WCAG AA for text use).
Keyboard-navigable nav, carousel, lightbox, and forms; visible focus states.
ARIA labels on icon-only buttons (WhatsApp, Call, Back-to-top).
Form fields with associated <label>s and inline error messaging.

12. PERFORMANCE


Use next/image everywhere with proper sizes/priority (hero image only) to avoid layout shift.
Lazy-load below-the-fold sections and gallery images.
Minimize client-side JS: mark sections as Server Components where no interactivity is needed; only Hero, Testimonials carousel, Gallery lightbox, Counters, and forms need "use client".
Preload key fonts, avoid font layout shift (font-display: swap).
Target Lighthouse scores of 90+ across Performance, Accessibility, Best Practices, SEO.
